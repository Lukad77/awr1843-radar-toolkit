本仓库实现了一个自研的轻量级 C++ 日志系统，核心位于 awr1843_dca1000_read/Logger.h（单头文件、零依赖），采用「单例 + 观察者 + 生产者-消费者队列」架构，提供控制台与文件双输出。

## 架构与组件
- LogLevel：四级枚举 Debug / Info / Warn / Error，通过 to_cstr() 映射为字符串标签。
- LogRecord：携带时间戳、级别、线程 ID 与消息体的最小记录结构。
- LogQueue：基于 std::queue + std::condition_variable 的阻塞队列，支持 shutdown() 优雅退出。
- LogSink 抽象层：定义 write(const LogRecord&) 接口，当前内置 ConsoleSink（std::cout）与 FileSink（std::ofstream append）。
- Logger 单例：内部维护一个独立工作线程，循环从队列弹出记录并广播给所有注册的 LogSink；析构时关闭队列、等待线程 join 并关闭文件句柄。

## 格式化与 API
- 使用 {} 占位符的简易可变参数拼接：format_Message(format, args...) 将任意可 << 的类型经 to_string_helper 转字符串后按顺序替换 {}，多余参数直接追加到末尾。
- 便捷入口：debug/info/warn/error(const std::string& fmt, Args&&...)，均走同一 log(LogLevel, ...) 路径入队。
- 默认格式：YYYY-MM-DD HH:MM:SS [LEVEL] (tid=...) message。

## 使用现状
- 模块已包含 #include "Logger.h"（如 awr1843_dca1000_read.cpp、RealTimeProcessor.h），但当前代码中尚未出现 Logger::getInstance().info(...) 等实际调用，说明日志框架已就绪但尚未集成到业务逻辑中。
- 未提供全局宏（如 LOG_INFO）或日志级别过滤开关，需显式注册 sink 并通过单例调用。

## 开发者约定
1. 通过 Logger::getInstance() 获取唯一实例，避免自行构造。
2. 在应用启动阶段注册所需 sink（至少 ConsoleSink，可选 FileSink），并在程序退出前让 Logger 析构以完成 flush。
3. 使用 {} 占位符传递可 << 类型，注意参数数量应与 {} 个数匹配，否则多余参数会被拼接到末尾。
4. 如需新增输出目标（网络、syslog 等），继承 LogSink 并实现 write 即可，无需修改核心逻辑。
5. 当前无日志级别阈值控制，所有级别均会入队输出；若需过滤可在 sink 侧判断 rec.level。
