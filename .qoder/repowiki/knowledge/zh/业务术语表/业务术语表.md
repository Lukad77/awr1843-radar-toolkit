### AWR1843 毫米波雷达
- 定义：德州仪器（TI）生产的 77GHz 毫米波雷达芯片，支持 FMCW 调制，具有多发射多接收天线阵列，常用于汽车防撞、人体检测、手势识别等场景。在本项目中作为被采集的信号源，通过 DCA1000 采集卡将原始 ADC 数据以 LVDS 形式传输至主机。
- 别名：AWR1843、TI AWR1843、毫米波雷达

### DCA1000 数据采集卡
- 定义：德州仪器配套的 LVDS 数据采集卡，负责将 AWR1843 雷达输出的高速串行数据转换为以太网 UDP 流，并提供 FPGA 配置接口。在项目中通过 UDP 命令通道（端口 4096）控制其工作状态，通过数据通道（端口 4098）接收原始 ADC 数据流。
- 别名：DCA1000、数据采集卡、LVDS 采集卡

### mmWave CLI 命令
- 定义：德州仪器 mmWave 雷达设备的命令行接口协议，通过串口发送文本命令来配置雷达工作参数（如 profileCfg、frameCfg、channelCfg）和控制采集流程（sensorStart/sensorStop）。项目中的 .cfg 配置文件即为 mmWave CLI 命令的集合，由 AWR1843Controller 逐行解析并下发。
- 别名：CLI 命令、雷达配置命令、mmWave 命令

### TLV 数据格式
- 定义：TI mmWave demo 的标准数据封装格式，采用 Type-Length-Value 三元组结构组织不同类别的数据（如检测点云、Range-Doppler 热图、静态功率谱等）。帧头包含 magic word `02 01 04 03 06 05 08 07`，后续跟随多个 TLV 单元，每个单元包含数据类型标识符、长度和数据体。
- 别名：TLV、Type-Length-Value

### I/Q 交织数据
- 定义：TI 雷达数据中复数信号的存储格式，每个采样点的实部（I）和虚部（Q）分量交替存放，占用 4 字节（2×int16）。DataParser 模块负责将此交织格式解复用为独立的复数矩阵，供后续 FFT 等信号处理算法使用。
- 别名：IQ 数据、复数数据、ADC 数据

### chirp 信号
- 定义：FMCW（调频连续波）雷达的基本调制单元，指频率随时间线性变化的正弦波信号。一帧数据由多个 chirp 组成，每个 chirp 包含固定数量的 ADC 采样点。项目中的 RadarParams 定义了每帧的 chirp 数量（numChirpsEachFrame）和每个 chirp 的采样点数（numADCSamples）。
- 别名：chirp、线性调频信号、FMCW 脉冲

### seqNum 帧重组
- 定义：针对 DCA1000 连续 UDP 数据流的帧边界恢复算法。由于网络传输可能导致数据包乱序或跨帧分割，系统通过包头中的 seqNum 序号计算每个包的偏移位置，将其 memcpy 到正确位置，最终还原出完整的雷达帧数据。这是高吞吐实时采集的关键技术。
- 别名：序号重组、帧重建、packet reassembly

### UnlockQueue 无锁队列
- 定义：基于原子操作实现的环形缓冲区，用于 UDP 接收线程与数据处理线程间的高性能数据传递。采用 memory_order 内存序保证并发安全，当队列满时允许覆盖旧数据（"allow override"），适合实时流处理场景，避免阻塞主采集流程。
- 别名：无锁队列、环形队列、producer-consumer queue

### RealTimeProcessor 实时处理器
- 定义：实现生产者-消费者模式的批处理组件，负责累积一定数量（FRAME_BATCH_SIZE=500）的解析后数据帧后再批量写入文件，减少 I/O 频率以提高数据完整性。支持两种写盘模式：解析后的复数数据（#if 1）或原始 ADC 字节（#if 0）。
- 别名：实时处理器、批处理组件、数据落盘器

### net_compat 兼容层
- 定义：跨平台网络 API 抽象层，将 Windows winsock2 与 POSIX BSD socket 的差异收口到单一头文件中，提供统一的 SOCKET 类型、net_startup/net_cleanup 初始化函数、错误码处理等接口，使上层 UDP 收发代码无需关心底层平台差异。
- 别名：网络兼容层、socket 抽象、跨平台网络
