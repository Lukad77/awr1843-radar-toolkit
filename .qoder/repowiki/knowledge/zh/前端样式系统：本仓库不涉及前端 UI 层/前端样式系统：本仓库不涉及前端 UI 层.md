经全面检索，该仓库为纯 C++ 命令行工具，面向 TI AWR1843 毫米波雷达与 DCA1000 采集卡的数据采集与处理。代码库中不存在任何 CSS、SCSS、HTML、JS/TS 等前端资源文件，也未引入任何前端框架或样式库（如 Tailwind、Bootstrap、styled-components 等）。项目通过控制台输出日志与状态信息，不包含图形界面或 Web 前端部分，因此 `frontend_style` 类别不适用于此仓库。
