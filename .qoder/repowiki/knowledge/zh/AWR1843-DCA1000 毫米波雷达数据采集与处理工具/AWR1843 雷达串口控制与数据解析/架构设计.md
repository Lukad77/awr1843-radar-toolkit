本模块按“抽象接口 → 平台实现 → 适配器 → 业务控制器”四层组织：
- `SerialPort.h` 定义纯虚接口 `open/close/send/setReceiveCallback`，作为上层对串口的唯一依赖。
- `WzSerialportPlus.{h,cpp}` 是第三方跨平台串口库（Windows 用 WinAPI `CreateFile/SetupComm/SetCommState/ReadFile`，POSIX 用 `termios` + `O_NONBLOCK`），内部以独立线程轮询 `read`/`ReadFile` 并通过 `std::function<void(char*,int)>` 回调推送字节；波特率通过 `baudrateToSpeed` 映射到 `B*` 常量，支持至 921600（注释标注为 AWR1843 数据口默认）。
- `WzSerialPortAdapter.h` 继承 `SerialPort`，将 `WzSerialportPlus` 暴露的 `char*` 签名适配为接口的 `const char*`，仅做薄包装。
- `AWR1843Controller.h`（header-only，同名 .cpp 为空）承载全部业务逻辑：维护 CLI 端口（`WzSerialPortAdapter cliPort`，默认 COM6:115200）和数据端口（`WzSerialportPlus dataPort`，默认 COM8:921600），构造函数可选自动打开并加载 `.cfg` 配置文件（逐行写入 CLI 端口，遇 `sensorStart` 停止）；`parseConfigParams` 从 `profileCfg/frameCfg/channelCfg` 推导 `ConfigParams`（距离/速度分辨率、最大范围等）；数据侧通过 `handleReceivedData` 把回调字节追加到 `byteBuffer`（带 `maxBufferSize=32768` 环形覆盖保护 + `bufferMutex` 互斥），再由 `postProcessDataBuf`/`parseData18xx` 基于魔术字 `0x02,0x01,0x04,0x03,0x06,0x05,0x08,0x07` 查找帧头、解析 TLV（检测点、RD 热图等），输出 `ProcessedFrame`。
依赖方向严格单向：`AWR1843Controller` → `WzSerialPortAdapter` → `SerialPort` ← `WzSerialportPlus`，不反向依赖上层。
