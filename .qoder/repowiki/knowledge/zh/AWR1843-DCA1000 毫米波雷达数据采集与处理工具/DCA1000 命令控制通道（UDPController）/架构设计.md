本模块由三个文件组成，职责清晰分层：
- `net_compat.h`：纯 API 映射的跨平台兼容层，在 `netcompat` 命名空间内提供 `net_startup/net_cleanup/net_close/net_last_error/net_would_block/net_set_nonblocking` 等 inline 函数，把 Windows Winsock2 与 POSIX BSD socket 的差异收口，使上层代码不感知平台。
- `UDPController.h`：定义 `CommandCode` 强类型枚举（RESET_FPGA / RECORD_START / PLAYBACK_STOP 等 13 个命令码）、协议常量（`CONFIG_HEADER=5aa5`、`CONFIG_FOOTER=aaee`、`HEADER_Num=0xa55a`、`FOOTER_Num=0xeeaa`）以及 `UDPController` 类接口；内部维护 `_destIp=192.168.33.180`、`_srcIp=192.168.33.30`、`_destPort=4096` 等连接参数。
- `UDPController.cpp`：实现构造时绑定本地 4096 端口、析构时释放 socket；`_sendCMD` 将 `CommandCode` 经 `cmd_to_string` 查表转为 4 字节 hex 串，拼接 header+cmd+length+body+footer 后以十六进制字节流 `sendto` 到 DCA1000，再 `recvfrom` 阻塞等待响应（默认 1s 超时），返回原始字节缓冲。
依赖方向：UDPController → net_compat；无对外业务耦合，仅暴露 `std::vector<uint8_t>` 形式的原始帧，后续由 DataParser 解析。
