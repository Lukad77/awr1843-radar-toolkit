模块由三个文件组成：
- `UdpReceiver.h/.cpp` 暴露 `UDPReceiver` 类，封装 UDP socket 生命周期与三种接收模式：`BLOCKING`（调用方在本地循环 recvfrom）、`ASYNC_THREAD`（预留，未启用）、`QUEUE_BASED`（后台线程非阻塞 recvfrom + 无锁环形缓冲）。构造时通过 `netcompat::net_startup()` 初始化平台网络栈，析构时统一关闭 socket 并 cleanup。
- 内部协议结构 `packet_t` 使用 `#pragma pack(1)` 对齐，固定 1466 字节（4B seqNum + 6B byteCnt + 1456B payload），对应 DCA1000 默认包大小 `PACKET_SIZE_DEFAULT`。
- 帧重组逻辑集中在 `ReadDataBlocking` / `GetFramesFromQueue` / `SortPackets`：先根据 `bytesInFrame` 与 `packetSize - 10` 计算首包偏移 `lastFrameRemainBytes`，再按 `ceil((lastFrameRemainBytes + frameNum * bytesInFrame) / payloadSize)` 拉取剩余包，最后按 seqNum 重排到连续输出 buffer。
- `unlock_queue.h` 提供模板化无锁单生产者/多消费者环形队列 `UnlockQueue<T>`，容量自动向上取 2 的幂，Put/Get 使用 `memcpy` 两段拷贝避免跨环边界；`Get_wait` 以 1ms 粒度忙等超时。`UDPReceiver` 仅在 `QUEUE_BASED` 模式下构造该队列并通过 `data_ready_cv_` 通知消费端。
- 依赖方向单向：`UdpReceiver` → `unlock_queue` + `net_compat.h`；统计信息通过独立 `stats_mutex_` 保护，与数据路径解耦。
